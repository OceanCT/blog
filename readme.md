# 博客复更

一直觉得，平时学到的东西、想过的问题，多少该记下来一些。但我是个懒人，一想到还得坐下来，把脑子里的东西一个字一个字敲出来，往往就算了。想着以后再写，博客也就一直没怎么更新。

有了 Codex 之后，记录这件事轻松了不少。现在甚至可以直接用语音输入，把刚才在想什么、哪里没弄懂、后来又是怎么想通的说出来，再慢慢整理成文章。对我来说，省下手敲的这一步，就已经少了很多拖着不写的理由。

所以，到了 2026 年下半年，这个博客又活过来了。

先把想记的写下来吧。以后再翻到这些文章，也能想起自己当时是怎么一点点弄明白的。
